## The EPAC Framework

EPAC (Expert-Planner-Actor-Critic) is a four-role framework for enterprise agentic AI developed by James Thomason. Every scorecard follows four phases:

1. **Expert Capture** — Gathers your specification, restates assumptions, confirms scope
2. **Planner** — Builds a structured analytical plan before any scoring begins
3. **Actor** — Executes the plan: analyzes documents, conducts web research, scores dimensions
4. **Critic** — Validates all outputs against six checklists: internal consistency, evidence quality, hallucination detection, analytical rigor, completeness, and audit trail

The Critic catches errors that traditional scorecard tools miss — inverted scale misapplications, fabricated statistics, unsupported confidence levels, and math mistakes.
